# Android ➜ Debian GNOME via VNC (English default)

This setup script turns a Debian system into a GNOME desktop you can reach via VNC and SSH.  
**Defaults:** English (`en_US.UTF-8`), GNOME desktop, SSH on port **10022**, VNC on display **:1** (TCP **5901**).

## 1) Run the setup on the device
Copy and run:

```bash
chmod +x ./android16-terminal.sh
./android16-terminal.sh
